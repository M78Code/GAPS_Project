# GAPS vs 闪烁体：数据预处理对比

---

## 一览表

| 方面 | GAPS反粒子识别 | 闪烁体波形位置推定 |
|------|-------------|-------------|
| **原始数据格式** | GEANT4模拟数据 | .dat二进制文件 |
| **特征维度** | ~5D稀疏（hit点） | 2×1024D密集（波形） |
| **数据结构** | 不规则点云（稀疏） | 规则时间序列（密集） |
| **样本数/文件** | 多个反粒子事件 | 多个粒子事件 |
| **标签** | 2分类（反陽子/反重陽子） | 连续值（位置cm） |
| **处理目标** | hit点 → 图结构 | 波形 → 张量 |
| **模型架构** | GNN（图） | CNN/LSTM（序列） |

---

## 详细对比

### 📊 GAPS反粒子识别

**Step 1：原始数据读取**
```python
# 从GEANT4数据读取
hit_data = loader.load_geant4_event(event_id)
# 输出: [num_hits, features]
#   features: [x, y, z, energy, time, ...]
```

**Step 2：特征提取**
```python
# 提取节点特征
node_features = extract_node_features(hit_data)
# [num_nodes, feature_dim]
# x, y, z 坐标归一化到[-1, 1]
# energy, time 归一化
```

**Step 3：图构造（核心处理）**
```python
# k-NN边构造
edge_index, edge_attr = construct_edges_knn(
    node_features, 
    k=10
)
# 输出:
#   edge_index: [2, num_edges]（源→目标）
#   edge_attr: [num_edges, 1]（距离权重）
```

**Step 4：转换为图数据**
```python
# 转为PyTorch Geometric格式
data = Data(
    x=node_features,           # [num_nodes, 5]
    edge_index=edge_index,     # [2, num_edges]
    edge_attr=edge_attr,       # [num_edges, 1]
    y=label                    # 0 or 1
)
```

**数据流**：
```
GEANT4数据
  ↓ (读取hit点)
Hit点云 [100点, 5维]
  ↓ (提取特征+归一化)
节点特征 [100, 5]
  ↓ (构造k-NN边)
图结构 (100节点, 1000条边)
  ↓ (转格式)
PyTorch Geometric Data
  ↓
GNN模型输入
```

**关键特点**：
- ✅ **稀疏**：只有hit点才有数据
- ✅ **非结构化**：点的数量不固定
- ✅ **需要特殊处理**：必须构造图
- ✅ **强依赖几何**：空间关系很重要

### 📊 闪烁体波形位置推定

**Step 1：原始数据读取**
```python
# 从.dat文件读取
event = read_dat_file('run7_65.dat')
# 输出: 
#   CH0_waveform: [1024]（左端）
#   CH1_waveform: [1024]（右端）
#   CH2_waveform: [1024]（触发，忽略）
#   CH3_waveform: [1024]（触发，忽略）
#   label: 65（位置，从文件名提取）
```

**Step 2：通道选择**
```python
# 只保留CH0+CH1
waveform = np.stack([CH0, CH1])  # [2, 1024]

# 忽略Header信息
# （Baseline, Amplitude, Charge, LeadingEdgeTime等）
```

**Step 3：波形归一化**
```python
# 幅度归一化（可选的前处理）
waveform_norm = (waveform - waveform.mean()) / waveform.std()

# 或保持原样直接输入模型
```

**Step 4：信号脉冲切割（可选）**
```python
# 从1024个样本中切出有效脉冲部分
# 检测信号起点和终点
pulse_start, pulse_end = detect_pulse(waveform)
pulse_waveform = waveform[:, pulse_start:pulse_end]
# 可能变成 [2, 300] 之类
```

**Step 5：转换为张量**
```python
# 转为PyTorch张量
waveform_tensor = torch.FloatTensor(waveform)  # [2, 1024]
label_tensor = torch.FloatTensor([position])   # scalar
```

**数据流**：
```
.dat文件
  ↓ (读取4通道波形)
4通道波形 [4, 1024]
  ↓ (提取CH0+CH1)
2通道波形 [2, 1024]
  ↓ (可选：脉冲切割)
脉冲波形 [2, 300]（如果切割）
  ↓ (归一化)
归一化波形 [2, 1024]
  ↓ (转格式)
PyTorch张量 [2, 1024]
  ↓
CNN/LSTM模型输入
```

**关键特点**：
- ✅ **密集**：每个通道都有1024个样本
- ✅ **结构化**：固定维度[2, 1024]
- ✅ **处理简单**：直接用或略做归一化
- ✅ **强依赖时间结构**：波形的形状很重要

## 关键差异

### 1️⃣ 数据维度

**GAPS**：
```
不固定！
  事件1：150个hit点 → 150节点
  事件2：80个hit点 → 80节点
  事件3：200个hit点 → 200节点
→ 需要动态处理（可变节点数）
```

**闪烁体**：
```
固定！
  每个事件都是：2通道 × 1024样本
  事件1：[2, 1024]
  事件2：[2, 1024]
  事件3：[2, 1024]
→ 可以固定batch处理
```

### 2️⃣ 图构造

**GAPS**：
```
必须做 🔴
hit点 → 节点特征 → k-NN连接 → 边 → 图对象
（核心处理步骤）
```

**闪烁体**：
```
不需要 ✓
波形直接用，或直接输入模型
（不涉及图概念）
```

### 3️⃣ 数据性质

**GAPS**：
```
稀疏 + 不规则
  • 只有hit点有数据
  • 点的位置不规则
  • 不能简单地grid化
  → 必须用图结构
```

**闪烁体**：
```
密集 + 规则
  • 所有时间点都有值
  • 固定采样率
  • 可以直接用CNN
  → 时间序列处理
```

### 4️⃣ 模型兼容

**GAPS**：
```
GNN（图神经网络）
  输入：图对象 (nodes, edges)
  
不能用CNN或LSTM
  ✗ CNN需要固定grid
  ✗ LSTM不适合节点聚合
```

**闪烁体**：
```
CNN或LSTM（序列模型）
  输入：[batch, channels, timesteps]
  
不能用GNN
  ✗ 没有节点和边的概念
  ✗ GNN为了图结构优化，这里浪费
```

## 代码框架对比

### GAPS预处理框架

```python
# src/data_loader.py + src/graph_builder.py

class GAPSPreprocessor:
    def process_event(self, event_id):
        # 1. 加载GEANT4数据
        hit_data = self.loader.load_event(event_id)
        
        # 2. 提取节点特征
        node_features = self.extract_node_features(hit_data)
        
        # 3. 构造图（关键步骤）
        edge_index = self.build_knn_graph(node_features)
        
        # 4. 转为Data对象
        data = self.to_pytorch_geometric(node_features, edge_index)
        
        return data
```

### 闪烁体预处理框架

```python
# src/scintillator_preprocessor.py

class ScintillatorPreprocessor:
    def process_file(self, filepath):
        # 1. 读取.dat文件
        waveform, label = self.read_dat(filepath)
        
        # 2. 提取CH0+CH1（简单）
        waveform = waveform[[0, 1], :]  # [2, 1024]
        
        # 3. 可选：脉冲切割
        if self.cut_pulse:
            waveform = self.cut_pulse(waveform)
        
        # 4. 转为张量
        tensor = torch.FloatTensor(waveform)
        
        return tensor, label
```

## 时间投入对比

| 任务 | GAPS | 闪烁体 |
|------|------|--------|
| 数据读取 | ⭐ 中等（需要理解GEANT4格式） | ⭐ 简单（二进制读取） |
| 特征提取 | ⭐⭐ 复杂（节点特征工程） | ⭐ 简单（直接用波形） |
| **图构造** | ⭐⭐⭐ **最复杂**（k-NN+边） | ❌ 不需要 |
| 数据格式转换 | ⭐ 中等 | ⭐ 简单 |
| 总时间 | **1.5～2周** | **2～3天** |

## 总结：能共用吗？

| 代码部分 | 能共用？ | 原因 |
|---------|--------|------|
| **数据加载** | ❌ 否 | 格式完全不同（GEANT4 vs .dat） |
| **特征工程** | ❌ 否 | GAPS有图构造，闪烁体无 |
| **归一化** | ⚠️ 部分 | 概念相同但应用不同 |
| **数据分割** | ✅ 可共用 | 都需要train/val/test分割 |
| **模型架构** | ❌ 否 | GNN vs CNN/LSTM |
| **训练循环** | ✅ 部分共用 | 都需要train_epoch, validate |
| **评估指标** | ❌ 否 | GAPS用Rejection Curve，闪烁体用MAE |

## 实际建议

### 不要试图共用预处理代码

虽然概念上都是"数据预处理"，但：
- ✅ **分别写两套预处理**（各2-3个脚本）
  - 代码清晰，维护容易
  - 逻辑不混乱
  
- ❌ **不要硬是共用**
  - 会导致代码复杂
  - 维护困难
  - 调试困难

## 最后的话

两个项目的数据预处理**概念上都是"清理数据+转成模型可用的格式"**，但：

- **GAPS**：稀疏点云 → 图结构（复杂）
- **闪烁体**：时间序列 → 张量（简单）

**建议**：
1. **分别实现两套预处理**（各自独立）
2. **共用通用工具**（数据分割、归一化等）
3. **不要硬是共用**（会使代码混乱）

两个项目可以并行，但预处理代码最好分开写。
