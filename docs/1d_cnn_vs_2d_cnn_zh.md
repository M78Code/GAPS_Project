# 为什么用1D CNN：波形数据中的1D CNN vs 2D CNN

## 结论

**波形数据（时间序列）应使用1D CNN，2D CNN不适合。**

---

## 数据形状的本质

本项目的数据形状是 `[2, 1024]`，但这不是"图像"。

```
CH0: [点1, 点2, 点3, ..., 点1024]  ← 时间序列（时间轴）
CH1: [点1, 点2, 点3, ..., 点1024]  ← 时间序列（时间轴）
```

- **1024 的方向**：时间轴（采样点）→ 相邻的点在物理上有意义
- **2 的方向**：CH0 和 CH1 是两个独立的传感器 → 它们之间没有空间上的相邻关系

---

## 2D CNN 不适合的原因

2D CNN 适合具有"二维空间结构"的数据。

```
图像的例子：[高度, 宽度]
→ 纵向和横向的相邻像素都有空间意义
→ 二维卷积核可以学习空间模式
```

对本项目的数据，在 CH0 和 CH1 之间（2 的方向）做卷积**没有物理意义**。
CH0 和 CH1 是放置在不同位置的独立传感器，它们之间并不"空间相邻"。

---

## 1D CNN 适合的原因

PyTorch 中 1D CNN 的输入格式：

```
[batch, in_channels, length]
= [64,      2,        1024]
```

这里的 `in_channels=2` 与**图像 CNN 中 RGB 三通道的概念完全相同**。

```
图像（RGB）：  [batch, 3,  H,    W  ] → Conv2d 在 H×W 空间上滑动
波形（2ch）：  [batch, 2,  1024     ] → Conv1d 在时间轴上滑动
```

卷积核沿**时间轴方向滑动，同时读取 CH0 和 CH1 对应时间点的值**，
自动学习两个通道之间的关系。

---

## 总结

| | 1D CNN | 2D CNN |
|---|---|---|
| 适合的数据 | 时间序列、波形 | 图像、频谱图 |
| 卷积方向 | 仅沿时间轴 | 时间轴 × 频率／空间轴 |
| 多通道支持 | 以 `in_channels` 形式天然支持 | 需要二维空间结构 |
| 本项目数据 | **正确选择** | 不适合（2 的方向无空间意义） |

两个通道不是"高度"，而是 `in_channels`。1D CNN 原生支持多通道输入，是波形数据分析的最佳选择。

---

## 参考：PyTorch 实现示例

```python
import torch.nn as nn

# 输入: [batch, 2, 1024]
conv = nn.Conv1d(in_channels=2, out_channels=32, kernel_size=7)
# 卷积核沿时间轴滑动，同时读取 CH0 和 CH1
# 输出: [batch, 32, 1018]
```
