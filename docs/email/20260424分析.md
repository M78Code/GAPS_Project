  🎯 简单答案

  runNN_XX.dat 的含义：

  NN = 运行编号（第几次实验运行）
  XX = 粒子通过的真实位置（正确标签），单位：cm

  例如：
    run7_65.dat  → 第7次运行，粒子位置=65cm
    run8_55.dat  → 第8次运行，粒子位置=55cm
    run9_15.dat  → 第9次运行，粒子位置=15cm

  🔍 数据结构（单个文件内）

  run7_65.dat 包含多个事件：

  事件1 → 波形数据(CH0+CH1) → 标签：65cm ✓
  事件2 → 波形数据(CH0+CH1) → 标签：65cm ✓
  事件3 → 波形数据(CH0+CH1) → 标签：65cm ✓
    ...

  为什么标签都是65cm？
  因为每次运行时，粒子通过的位置是固定的。一个run*.dat文件记录的是该次运行中多个粒子事件的波形，但它们都通过同一位置。

    CH0信号弱 ▓
