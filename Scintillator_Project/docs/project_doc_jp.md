## 1. プロジェクト概要

### 1.1 背景

本プロジェクトは大場章徳氏（2022年入学，学籍番号202204429）の卒業研究を引き継いだものである。大場氏は伝統的な信号処理手法（CFD法・THR法・TLE法・電荷比法）による粒子位置推定を実装し，完全な実験データセットを構築した。

本プロジェクトの目標は，**深層学習（1D CNN）を用いて波形データから直接粒子位置を推定し，伝統的手法の精度を超えること**である。

### 1.2 物理的背景

シンチレータ検出器の両端には光電子増倍管（PMT）がそれぞれ取り付けられており，CH0（左端）とCH1（右端）に対応している。粒子がシンチレータを通過する際，光子が両端に向かって伝播し，到達時刻差（Δt）と振幅比（R₀）が粒子位置情報を担う。

```
  [CH0 PMT] ←────── シンチレータ (125 cm) ──────→ [CH1 PMT]
      │                                                 │
      │←── 位置が左に近いほど，CH0信号が強く，早く到達 ───│
      │←── 位置が右に近いほど，CH1信号が強く，早く到達 ───│
```

**Δt の物理的単調性**（データにより検証済み）：

| 位置 | 平均 Δt (index) | 説明 |
|------|----------------|------|
| 15 cm | +27.7 | CH1が遅く到達（左端寄り） |
| 75 cm | ≈ 0 | 中央，両端等距離 |
| 140 cm | −30.4 | CH1が早く到達（右端寄り） |

## 3. 前処理パイプライン

### 3.1 `.dat` ファイル解析

**スクリプト**：`src/preprocessor.py`，`src/data_parse/dat_file_reader.py`

処理手順：
1. バイナリ `.dat` ファイルを読み込む
2. Header（Baseline・Amplitude・Charge・LeadingEdgeTime）をスキップ
3. CH0・CH1 波形（各1024点）を抽出
4. ファイル名から位置ラベル（`XX`）を取得
5. JSON 形式に変換し `dataset/processed/` へ保存

### 3.2 データセット分割

**スクリプト**：`src/data_parse/split_dataset.py`

70/15/15 でランダム分割し，`dataset/split/train.json`・`val.json`・`test.json` として保存。

### 3.3 Dataset クラス（ScintillatorDataset）

**ファイル**：`src/data_parse/scintillator_dataset.py`

```python
ScintillatorDataset(json_path, normalize=True, roi=(450, 800))
```

処理手順（順序通り）：
1. JSON を読み込み，全イベントを取得
2. CH0・CH1 を結合して shape `[2, 1024]` の NumPy 配列を生成
3. **ROI 切り出し**（`roi=(450, 800)` の場合）：`waveform = waveform[:, 450:800]` → shape `[2, 350]`
4. **合同正規化**：`max_abs = np.max(np.abs(waveform))`，2チャンネル共通の最大値で正規化

**なぜ合同正規化（独立正規化でなく）を使うのか？**

独立正規化では各チャンネルを自身の最大値で除算するため，CH0/CH1 間の振幅比情報が失われる。  
電荷比 R₀ = ln(Q_R / Q_L) は位置情報を担う重要な物理量であり，合同正規化によりその相対的な振幅比が保存され，モデルがこの特徴を学習できる。

### 3.4 DataLoader

**ファイル**：`src/data_parse/data_loader.py`

```python
make_dataloaders(split_dir, batch_size=64, num_workers=0)
```

| パラメータ | train | val/test | 理由 |
|-----------|-------|----------|------|
| shuffle | True | False | 訓練時はシャッフルで順序バイアスを防ぐ，検証/テストは再現性のため固定 |
| batch_size | 64 | 64 | メモリと精度のバランス |
| num_workers | 0 | 0 | Mac環境では0が最も安定 |

## 4. モデルアーキテクチャ

### 4.1 CNN1D

**ファイル**：`src/models/cnn1d.py`

波形回帰用の軽量 1D CNN。

```
入力: [batch, 2, 350]  (2チャンネル × ROI 350点)
  │
  ├─ Conv1d(2→32, k=7) + BN + ReLU + MaxPool(2)   → [batch, 32, 175]
  ├─ Conv1d(32→64, k=5) + BN + ReLU + MaxPool(2)  → [batch, 64, 87]
  ├─ Conv1d(64→128, k=3) + BN + ReLU + MaxPool(2) → [batch, 128, 43]
  │
  ├─ AdaptiveAvgPool1d(1)  → [batch, 128, 1]  (入力長に依存しない)
  ├─ Squeeze              → [batch, 128]
  │
  ├─ Linear(128→64) + ReLU
  └─ Linear(64→1)
  
出力: [batch, 1]  (推定位置，単位 cm)
```

**パラメータ数**：44,257（約44K，非常に軽量）

**設計上の重要点**：`AdaptiveAvgPool1d(1)` により，モデルは入力長に依存しない。ROI ウィンドウサイズを変更してもモデル構造の修正が不要。

## 6. 評価

**スクリプト**：`src/scripts/evaluate.py`

評価手順：
1. `results/` 内でタイムスタンプが最新のモデルを自動検出（正規表現でフィルタリング）
2. テストセットに対して推論を実行し，MAE・RMSE・R² を計算
3. 各位置ごとの RMSE を集計
4. 結果を `results/{timestamp}_test_results.txt` に保存

**評価指標**：
- **MAE**：平均絶対誤差（大誤差の影響を受けにくい）
- **RMSE**：二乗平均平方根誤差（大誤差に敏感，大場論文との比較基準）
- **R²**：決定係数（1に近いほど良い）

## 7. 伝統的手法のベースライン

出典：大場章徳 卒業研究概要書（`清水研_202204429_大場章徳_卒業研究概要書.pdf`）表1

| 手法 | 単独 σ | 融合後 σ | 説明 |
|------|--------|---------|------|
| 電荷比法 | 11.6 cm | — | ln(Q_R/Q_L) → 位置推定 |
| THR法 | 4.99 cm | 4.95 cm | 固定閾値トリガー時刻差 |
| CFD法 | 5.30 cm | **4.93 cm** | 恒分数弁別器，最優 |
| TLE法 | 5.55 cm | 5.13 cm | 前縁時刻法 |

**CFD 融合法（4.93 cm）が深層学習で超えるべき目標ベースラインである。**

### 各手法の解説

**CFD法（Constant Fraction Discriminator，恒分数弁別器）**：  
信号がピーク値のある固定割合（例：20%）に達した時刻をトリガー時刻として定義する手法。信号振幅の変動による時刻測定誤差（walk）を排除できる最も精度の高い時刻測定法。CFD 時刻差 Δt = t_R(CFD) − t_L(CFD) は位置の線形関数であり，物理的根拠が明確。

**THR法（Threshold，固定閾値法）**：  
信号が固定電圧閾値を超えた時刻をトリガー時刻とする手法。実装が簡単だが，振幅変動の影響を受けやすい（走り=walk が大きい）。

**TLE法（Trailing/Leading Edge，前縁時刻法）**：  
信号の立ち上がり縁（または立ち下がり縁）の特定の点でトリガー時刻を定義する手法。THR 法の改良版に近いが，波形形状への依存性が異なる。

**電荷比法（Charge Ratio Method）**：  
R₀ = ln(Q_R / Q_L)（両チャンネルの積分電荷量の比の対数）を計算し，校正曲線から位置を推定する手法。単独では精度が低いが，時刻差法との融合で改善が見込まれる。

**残差加重融合（大場氏の中核的貢献）**：  
複数手法による位置推定結果を残差加重融合で統合。各手法の長所を補完することで，CFD+電荷比の融合が 4.93 cm を達成。

## 9. 問題分析と根本原因

### 9.1 CNN 初期性能が低かった根本原因

1. **入力ノイズが多い**：全1024点のうち約66%は純粋なノイズ（ベースライン領域）であり，特徴抽出を妨げていた
2. **独立正規化が物理情報を破壊**：チャンネルごとに独立に正規化すると，CH0/CH1 の振幅比（R₀）情報が消去される
3. **サンプル不均衡**：135cm（N=37）などの位置でサンプルが極端に少なく，モデルが十分に学習できない

### 9.2 各改善措置の効果

| 問題 | 対策 | 効果 |
|------|------|------|
| 入力ノイズ | ROI 固定ウィンドウ [450〜800] | RMSE 5.52→5.26 |
| R₀情報の損失 | 合同正規化（2ch共通 max_abs） | RMSE 5.26→5.03 |
| 学習不足 | epoch 数増加（200/300） | RMSE 5.03→4.87→4.78 |
| サンプル不均衡 | **未実施**：データ拡張 | 135cm の改善を期待 |

### Step 18：データ拡張

**目標**：135cm（N=37）・25cm（N=38）・35cm（N=39）などのサンプル希少位置の誤差改善

**案 A**：希少位置の波形にガウスノイズを加えて新サンプルを生成
```python
# 拡張サンプルの生成
noise = np.random.normal(0, 0.01, waveform.shape)  # σ=振幅の1%
aug_waveform = waveform + noise
```

**案 B**：DataLoader 内で希少位置をオーバーサンプリング
```python
# サンプル数の逆数に比例した重みを設定
weights = 1.0 / position_counts[labels]
sampler = WeightedRandomSampler(weights, num_samples=len(dataset))
```

**期待効果**：135cm 位置の RMSE を 10.94 cm から 7 cm 以下に改善；全体 RMSE は 4.5 cm 以下を見込む。
