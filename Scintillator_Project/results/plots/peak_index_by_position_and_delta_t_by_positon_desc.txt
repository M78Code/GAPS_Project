 图1：峰值index分布

  好消息：绝大多数事件的峰值集中在 550~650，候选窗口[450~800]基本覆盖。

  问题：有明显离群点，结合日志表格看：

  ┌───────┬──────────────────────────────┬─────────┬─────────┐
  │ 位置  │             异常             │ CH0 min │ CH1 min │
  ├───────┼──────────────────────────────┼─────────┼─────────┤
  │ 15cm  │ CH0有index≈60的事件          │ 57      │ 293     │
  ├───────┼──────────────────────────────┼─────────┼─────────┤
  │ 80cm  │ CH0有index≈1的事件           │ 1       │ 563     │
  ├───────┼──────────────────────────────┼─────────┼─────────┤
  │ 125cm │ CH0最大达到802，超出窗口上界 │ 397     │ 56      │
  └───────┴──────────────────────────────┴─────────┴─────────┘

  这些离群点不是真实信号，是噪声事件——波形中噪声峰比真正脉冲更深，导致argmin找错了位置。

  图2（日志）：Δt单调递减

  15cm → Δt = +27.7（CH1晚到，粒子靠近左端）
  75cm → Δt = ≈ 0.0（中间位置，两端等距）
  140cm → Δt = −30.4（CH1早到，粒子靠近右端）

  这是最重要的发现：Δt从+27.7到−30.4完美单调，完全符合物理规律。这证明：
  1. 时间差确实携带位置信息——CFD法有效的根本原因
  2. CNN的输入如果能保留这个Δt关系，就有机会学到它
