# 闪烁体位置推定技术报告

**日期**：2026-05-05
**作者**：李

---

## 1. 数据描述

### 1.1 数据来源
本研究使用大場同学卒业论文中采集的 TOF 闪烁计数器实验数据。
实验使用宇宙线缪子作为荷电粒子，通过上下触发器（AND）选别事象，
记录闪烁体（EJ200，150×16×0.5 cm）两端 PMT 的波形信号。

### 1.2 数据统计

| 项目 | 内容 |
|------|------|
| 总事象数 | 23,602 |
| 测量位置 | 15 个（15 cm ～ 140 cm） |
| 使用通道 | CH0（左端）、CH1（右端） |
| 采样点数 | 1024 samples / 事象 |
| 采样间隔 | 0.3125 ns |

### 1.3 数据分割

| 分割 | 事象数 | 比例 |
|------|--------|------|
| 训练集 | 16,514 | 70% |
| 验证集 | 3,533  | 15% |
| 测试集 | 3,555  | 15% |

各位置按比例分层分割，确保每个位置在三个分割中均有样本。

---

## 2. 模型架构

### 2.1 输入与输出
- **输入**：波形张量 `[batch, 2, 1024]`（CH0 + CH1，各 1024 点，按通道归一化）
- **输出**：预测位置 `[batch, 1]`（单位：cm）

### 2.2 网络结构（CNN1D）

| 层 | 类型 | 输出形状 |
|----|------|---------|
| Conv1 | Conv1d(2→32, k=7, pad=3) + BN + ReLU + MaxPool(2) | [batch, 32, 512] |
| Conv2 | Conv1d(32→64, k=5, pad=2) + BN + ReLU + MaxPool(2) | [batch, 64, 256] |
| Conv3 | Conv1d(64→128, k=3, pad=1) + BN + ReLU + MaxPool(2) | [batch, 128, 128] |
| Pool | AdaptiveAvgPool1d(1) | [batch, 128, 1] |
| FC1 | Linear(128→64) + ReLU | [batch, 64] |
| FC2 | Linear(64→1) | [batch, 1] |

**总参数量**：44,257

### 2.3 设计思路
- 使用 1D CNN 而非 2D CNN：两个通道（CH0/CH1）之间无空间关系，不适合 2D 卷积
- 三层卷积逐步提取局部波形特征（峰值形状、上升沿、下降沿）
- 每层加入 BatchNorm，稳定训练、加快收敛
- AdaptiveAvgPool 压缩时间轴，降低对波形长度的敏感性
- 选择回归输出而非分类，预测连续位置值

## 3. 训练设置

| 超参数 | 值 |
|--------|-----|
| 损失函数 | MSELoss |
| 优化器 | Adam |
| 初始学习率 | 3×10⁻⁴ |
| 学习率调度 | StepLR（每 20 epoch × 0.7） |
| Epochs | 100 |
| Batch Size | 64 |
| 设备 | Apple M3 MAX (MPS) |

学习率衰减曲线：

| Epoch 区间 | 学习率 |
|------------|--------|
| 1–20   | 3.0×10⁻⁴ |
| 21–40  | 2.1×10⁻⁴ |
| 41–60  | 1.47×10⁻⁴ |
| 61–80  | 1.03×10⁻⁴ |
| 81–100 | 7.2×10⁻⁵ |

最优验证集 val_loss = 31.86（Epoch 96），对应 RMSE = 5.64 cm。

## 5. 与传统方法对比

在相同的测试集上实现了两种传统位置推定方法：

| 方法 | RMSE (cm) | MAE (cm) |
|------|-----------|---------|
| 电荷量比法 | 10.87 | 8.29 |
| 时刻差法   | 12.77 | 9.35 |
| 组合法（传统最优） | 9.17 | 6.73 |
| **CNN（本研究）** | **5.52** | **3.35** |

CNN 相比传统最优方法（组合法）RMSE 提升 **39.8%**。

## 6. 局限性分析

### 6.1 样本不均衡
15 cm（N=6022）与 135 cm（N=239）之间事象数相差约 25 倍。
样本少的位置模型学习不充分，导致误差偏大。

**可能的改善方向**：
- 采集更多数据，尤其是 25 cm、35 cm、65 cm、135 cm
- 对样本少的位置进行过采样（数据增强）

### 6.2 离群点
15 cm 和 45 cm 存在误差超过 30 cm 的极端事象，可能是：
- 缪子斜入射（非垂直通过）
- 触发噪声事象
- 波形记录异常

**可能的改善方向**：预处理阶段加入波形质量筛选。

### 6.3 传统方法实现的局限
本报告中传统方法使用线性回归拟合，实际卒论中的实现细节可能有所不同，对比结果仅供参考。
