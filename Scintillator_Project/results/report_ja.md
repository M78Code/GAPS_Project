## 1. データの概要

### 1.1 データ出典
大場さんの卒業論文で取得された TOF シンチレーションカウンタの実験データを使用した。
実験では宇宙線ミューオンを荷電粒子として使用し、上下トリガーの同時計測（AND）によって
事象を選別したうえで、シンチレータ（EJ200，150×16×0.5 cm）両端の PMT 波形信号を記録した。

### 1.2 データ統計

| 項目 | 内容 |
|------|------|
| 総イベント数 | 23,602 |
| 測定位置 | 15 点（15 cm ～ 140 cm） |
| 使用チャンネル | CH0（左端）、CH1（右端） |
| サンプル数 | 1024 samples / イベント |
| サンプリング間隔 | 0.3125 ns |

### 1.3 データ分割

| 分割 | イベント数 | 割合 |
|------|-----------|------|
| 訓練セット | 16,514 | 70% |
| 検証セット | 3,533  | 15% |

各位置から比例的に層化分割し、すべての分割に各測定位置のサンプルが含まれるようにした。

## 2. モデルアーキテクチャ

### 2.1 入力・出力
- **入力**：波形テンソル `[batch, 2, 350]`（CH0 + CH1、ROI [index 450〜800] を切り出した 350 点、2チャンネル共通の max_abs で正規化）
- **出力**：予測位置 `[batch, 1]`（単位：cm）

**ROI 設定の根拠**：波形ピークは index 550〜650 付近に集中しており、index 450〜800 の窓でイベントの 99.97%（6個のみ窓外）をカバーする。不要な前後の平坦部分を除去することで学習効率を向上させた。

**正規化方式**：2チャンネルを同一の max_abs で正規化する「共通正規化」を採用した。チャンネル間の振幅比（R₀ = ln(Q_R/Q_L)）を保持するためであり、独立正規化ではこの位置情報が失われる。

### 2.2 ネットワーク構造（CNN1D）

| 層 | 種類 | 出力形状 |
|----|------|---------|
| Conv1 | Conv1d(2→32, k=7, pad=3) + BN + ReLU + MaxPool(2) | [batch, 32, 175] |
| Conv2 | Conv1d(32→64, k=5, pad=2) + BN + ReLU + MaxPool(2) | [batch, 64, 87] |
| Conv3 | Conv1d(64→128, k=3, pad=1) + BN + ReLU + MaxPool(2) | [batch, 128, 43] |
| Pool | AdaptiveAvgPool1d(1) | [batch, 128, 1] |
| FC1 | Linear(128→64) + ReLU | [batch, 64] |
| FC2 | Linear(64→1) | [batch, 1] |

**総パラメータ数**：44,257

### 2.3 設計方針
- 2D CNN ではなく 1D CNN を使用：CH0/CH1 の2チャンネルには空間的な関係がないため、2D 畳み込みは不適切
- 3層の畳み込みにより、波形の局所的特徴（ピーク形状・立ち上がり・立ち下がり）を段階的に抽出
- 各層に BatchNorm を追加し、学習の安定化と収束の高速化を図った
- AdaptiveAvgPool により時間軸を圧縮し、波形長への感度を低減
- 離散的な分類ではなく連続値の回帰として位置を予測

## 6. 課題と今後の展望

### 6.1 イベント数の不均衡
イベント数が少ない位置（25 cm・35 cm・65 cm・135 cm、N < 50）では誤差が大きい。
追加データの取得が最も直接的な改善策である。

### 6.2 外れ値事象
一部の位置において誤差が 30 cm を超える極端な外れ値事象が存在する。
原因として以下が考えられる：
- ミューオンの斜め入射（垂直でない通過）
- トリガーノイズ事象
- 波形記録の異常

前処理段階での波形品質フィルタリングの導入が有効と考えられる。

### 6.3 今後の発展方向
- **Transformer / Attention モデル**：波形は時系列データであり、自己注意機構による特徴抽出が有効な可能性がある
- **物理特徴の融合**：Δt・R₀ 等の物理量を CNN 特徴と組み合わせたハイブリッドモデル
- **不確定性推定**：MC Dropout 等による予測信頼区間の付与

### 6.4 従来手法実装の注意点
比較に用いた従来手法の数値は大場さんの卒業論文（表1）の記載値をそのまま使用した。
